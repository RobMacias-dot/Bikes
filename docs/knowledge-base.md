# Base de conocimiento

`mobile/assets/knowledge/manifest.json` declara el esquema y la versión. `v1/catalog.json` contiene perfiles, tipos de bicicleta, fabricantes, banderas rojas y 46 escenarios derivados de `Ex_sys_bike_FINAL.py`.

Validación recomendada antes de publicar una nueva versión: IDs únicos, sistemas existentes, riesgos en `low|medium|high|critical`, escenarios con diagnóstico y acción, y referencias de reglas resueltas. La interfaz debe presentar texto localizado y no incrustar reglas o compatibilidades en widgets.

Las marcas son identificadores de contexto, no una afirmación de interoperabilidad. Es obligatorio pedir modelo, serie, velocidades, interfaces, fluido o código pertinente antes de recomendar piezas/procedimientos específicos.
