# Privacidad — borrador para revisión antes de publicación

BiciFirme funciona sin cuentas, backend, anuncios, analítica ni telemetría. Las bicicletas y sus datos se guardan localmente en el dispositivo. No se envían al desarrollador.

Las funciones de compartir utilizan la aplicación que el usuario elija y requieren una acción explícita. Revisa el contenido antes de compartirlo. No escribas información personal o confidencial en las notas si no deseas conservarla en el dispositivo o incluirla en archivos compartidos.

Los futuros respaldos serán archivos controlados por el usuario. El correo de comentarios se abrirá únicamente tras una acción explícita y permitirá revisar/editar el borrador antes de enviarlo. Estas dos funciones todavía están pendientes de implementación.
